## 2026-06-26 - Omit only unused fields in list endpoints\n**Learning:** When using prisma `omit` to optimize payload size, we must thoroughly verify that the omitted fields are not used by the frontend components consuming the list. In this app, fields like slides and pollOptions are used in the detail view/studio but not in the history list, but we should always be careful about regressions. The code review confirmed that the patch works safely for the lists in `ContentHistory.tsx` and `Dashboard.tsx`, but raised a valid flag to make sure.\n**Action:** Double-check frontend consumers of API endpoints when omitting fields to ensure no breaking changes are introduced.
