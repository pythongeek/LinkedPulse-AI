## 2025-02-24 - Prisma FindMany Over-fetching Vulnerability
**Learning:** The database models (`Content`, `Topic`, `Persona`) in this application heavily rely on large JSON fields (`researchData`, `trendData`, `systemPrompt`, etc.) to store LLM data and analytical payloads. Because standard list endpoints used bare `findMany` queries, these large objects were being fetched from Postgres, deserialized, and serialized into JSON payloads even though the frontend list views didn't use them. This constitutes a significant bottleneck for memory usage and network serialization time in this architecture.
**Action:** Always use Prisma's `omit` feature (available in ^6.2.1) or `select` on `findMany` list endpoints for models known to contain large JSON/Text columns in this specific application.
