## 2024-07-01 - Prevent over-fetching on content findMany
**Learning:** The `GET /api/content` route returns a large list of `Content` models. The `Content` model contains multiple large JSON fields (`researchData`, `outline`, `sources`, `hookSuggestions`, `linkedinOptimization`, `competitiveAnalysis`, `slides`, `pollOptions`, `topicSignal`, `engagementActual`). Fetching this large payload can cause memory and network bottlenecks. The frontend code (e.g. `src/pages/ContentHistory.tsx` and `src/pages/Dashboard.tsx`) only requires a subset of these fields (id, contentType, status, engagementPrediction, title, body, createdAt) to render the list.
**Action:** Use Prisma's `omit` feature in `findMany` queries when large JSON payloads are returned and the client only needs minimal fields to avoid over-fetching.
