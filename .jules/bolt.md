## 2024-06-11 - Optimize Prisma list endpoints for models with large JSON fields
**Learning:** In a codebase leveraging PostgreSQL and Prisma where models have large unstructured `Json` fields (such as `Content` with `researchData` and `linkedinOptimization`, or `Topic` with `trendData`), list endpoints using `findMany` can suffer from significant performance bottlenecks due to over-fetching. These large strings are loaded into memory and sent over the network unnecessarily for list views. Prisma ^6.2.1 supports an `omit` attribute natively to easily bypass fetching these fields.
**Action:** When querying large datasets with Prisma where only basic metadata is required for list view representation, always use `omit` (or `select`) to exclude any large JSON or Text fields to improve database response times and reduce API memory footprint.
